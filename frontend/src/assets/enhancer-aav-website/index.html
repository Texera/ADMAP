How to Use the Image Viewer

Navigation

  • Arrow Keys - Navigate between images (← Previous | Next →)
  • Escape - Close the image viewer
  • Swipe Left/Right - Navigate on mobile devices

Zoom & Pan

  • Scroll Wheel - Zoom in/out
  • +/- Keys - Zoom in/out
  • Click & Drag - Pan around when zoomed
  • Pinch - Zoom on touch devices
  • Double-click - Toggle fit/fill zoom

Channel Controls

  • RGB Sliders - Adjust individual channel intensity (0-100%)
  • Gain Control - Amplify all channels together (0-500%)
  • Grayscale Button - View as grayscale
  • Reset Button - Return to default channel settings
  • Show Legend - Toggle channel information display

Information Panels

  • Show Metadata - Display experimental information (genotype, vector, etc.)
  • Show Atlas Position - View location in Allen Brain Atlas template
  • Channel Legend - See what each color channel represents

Keyboard Shortcuts

  • H - Toggle toolbar visibility
  • M - Toggle metadata panel
  • A - Toggle atlas panel
  • L - Toggle legend panel
  • G - Toggle grayscale
  • R - Reset channel settings
  • Esc - Close viewer

Tips

  • Use channel sliders to highlight different structures in the tissue
  • The legend shows which channels contain which markers (AAV, immunostaining, DAPI)
  • Hover over buttons to see more detailed information
  • On mobile, use the simplified toolbar with essential controls
  • The atlas panel helps locate structures within the mouse brain
